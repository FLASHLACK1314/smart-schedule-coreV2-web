# 教学班-行政班关联管理 - 前端开发文档

## 功能说明

**功能描述**：管理系统中的教学班与行政班的多对多关联关系，将行政班级的学生添加到教学班中

**主要业务**：
- 将行政班级添加到教学班（建立关联关系）
- 查询教学班-行政班关联列表（支持按教学班、行政班、学院、专业筛选）
- 删除教学班-行政班关联关系

**业务背景**：
- **教学班**（Teaching Class）是临时的上课组织单位，如"高等数学-张老师-计科2101+2102"
- **行政班级**（Class）是学生的固定组织单位，如"计科2101班"
- 一个教学班可以包含多个行政班级的学生（多对多关系）
- 示例：张老师教授的"高等数学"课包含计科2101和2102两个行政班的学生

**示例场景**：
- 新学期排课前，教务管理员需要将计科2101、2102、2103三个行政班添加到"高等数学-张教授"教学班
- 学生转专业后，需要从原教学班中移除原行政班关联

### 交互细节

#### 筛选区域

**教学班下拉框**：
- 数据源：调用教学班分页接口获取教学班列表
- 选择教学班后筛选该教学班的所有关联

**行政班下拉框**：
- 数据源：调用行政班分页接口获取班级列表
- 支持按学院→专业级联筛选

**学院下拉框**：
- 数据源：调用学院接口获取学院列表
- 选择学院后，自动清空并刷新专业下拉框和行政班下拉框

**专业下拉框**：
- 数据源：根据选择的学院调用专业接口筛选
- 仅在选择了学院后才启用
- 选择专业后，自动清空并刷新行政班下拉框

**查询按钮**：
- 点击后根据筛选条件查询第1页

**重置按钮**：
- 清空所有筛选条件
- 重新加载第1页数据

---

#### 表格操作

**删除按钮**：
- 点击后弹出二次确认对话框
- 确认后调用删除接口
- 删除成功后刷新当前页

### 添加对话框字段

**对话框标题**：添加教学班-行政班关联

**表单字段**：

| 字段名 | 类型 | 必填 | 交互说明 |
|--------|------|------|----------|
| 教学班 | string | 是 | 下拉框，选择教学班 |
| 行政班 | string | 是 | 下拉框，支持学院→专业级联筛选 |

**表单验证规则**：
- 教学班：必填，下拉选择
- 行政班：必填，下拉选择

**提交逻辑**：
- 表单验证通过后，调用添加接口
- 成功后关闭对话框并刷新列表到第1页
- 失败则显示错误提示，对话框保持打开

## 注意事项

1. **多对多关系理解**：
   - 一个教学班可以包含多个行政班
   - 一个行政班可以属于多个教学班（如体育课、选修课）
   - 本功能管理的是这种多对多关联关系

2. **级联筛选**：
   - 学院→专业→行政班三级级联
   - 清空上级选择时，需级联清空下级选项
   - 参考学生管理页面的级联实现

3. **权限控制**：
   - 仅 SYSTEM_ADMIN 和 ACADEMIC_ADMIN 可以添加/删除关联
   - 其他角色（TEACHER、STUDENT）仅可查看
   - 操作按钮需根据用户角色显示/隐藏

4. **删除约束**：
   - 删除关联后，该行政班的学生将不再属于该教学班
   - 可能会影响排课记录，建议后端增加约束检查

5. **表格显示优化**：
   - 表格应同时显示教学班和行政班的完整信息
   - 包含课程、教师、专业、学院等关联信息，方便用户确认
   - 同一教学班的多个行政班建议相邻显示（可按教学班名称排序）

6. **数据一致性**：
   - 添加关联时，避免重复添加相同的教学班-行政班组合
   - 建议后端做唯一性校验，前端也可以在添加前检查

7. **业务场景提示**：
   - 添加对话框可以提示用户"将把选中的行政班的所有学生添加到该教学班"
   - 删除对话框可以提示用户"将把该行政班的学生从教学班中移除"

8. **命名规范**：
   - 所有字段统一使用蛇形命名（snake_case）
   - 包括 URL 查询参数、请求体字段、响应体字段
