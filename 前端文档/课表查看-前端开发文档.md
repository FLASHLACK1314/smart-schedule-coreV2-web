# 课表查看 - 前端开发文档

## 功能说明

### 功能描述

以课表网格形式展示排课信息，支持按教师、学生、班级、教室四种维度查看。

### 主要业务

- 教师课表：查看指定教师在指定学期的所有课程安排
- 学生课表：查看指定学生在指定学期的所有课程安排
- 班级课表：查看指定行政班在指定学期的所有课程安排
- 教室课表：查看指定教室在指定学期的使用情况

### 业务背景

- 课表以周为单位展示，横轴为星期(1-7)，纵轴为节次
- 同一时间段可能有多门课程（不同周次）

## 页面功能

### 核心功能

- 查询方式切换（Tab切换：教师/学生/班级/教室）
- 下拉选择查询对象（根据Tab显示不同下拉框）
- 学期选择（下拉框）
- 课表网格展示（7列 x N行的网格）
- 周次筛选（可选，过滤特定周次的课程）

### 课表网格设计

```
┌─────────┬─────────┬─────────┬─────────┬─────────┬─────────┬─────────┐
│  节次   │  周一   │  周二   │  周三   │  周四   │  周五   │ 周六/日 │
├─────────┼─────────┼─────────┼─────────┼─────────┼─────────┼─────────┤
│  1-2节  │ 高等数学 │         │ 高等数学 │         │         │         │
│         │ 教学楼A  │         │ 教学楼A  │         │         │         │
├─────────┼─────────┼─────────┼─────────┼─────────┼─────────┼─────────┤
│  3-4节  │         │ 线性代数 │         │ 线性代数 │         │         │
│         │         │ 教学楼B  │         │ 教学楼B  │         │         │
├─────────┼─────────┼─────────┼─────────┼─────────┼─────────┼─────────┤
│  ...    │         │         │         │         │         │         │

```

### 单元格内容

| 内容 | 字段 | 说明 |
|------|------|------|
| 课程名称 | course_name | 必须显示 |
| 教师名称 | teacher_name | 可选显示 |
| 教室名称 | classroom_name | 可选显示 |
| 周次 | weeks_json | 鼠标悬停显示或小字显示 |

### 交互说明

1. **Tab切换**：
   - 切换Tab后，清空当前选择并显示对应的下拉框
   - 四个Tab：教师课表、学生课表、班级课表、教室课表

2. **数据加载**：
   - 选择查询对象和学期后，自动加载课表
   - 加载中显示loading状态

3. **周次筛选**：
   - 提供周次下拉选择（如1-20周）
   - 选择后过滤只显示包含该周次的课程

4. **单元格点击**：
   - 点击课表单元格可查看详细信息（弹窗）
   - 显示完整课程信息、周次等

5. **空状态处理**：
   - 未选择查询条件时显示引导提示
   - 无课表数据时显示空状态提示

## 工具函数建议

### 解析周次JSON

```typescript
/**
 * 解析周次JSON字符串为数组
 */
function parseWeeksJson(weeksJson: string): number[] {
  try {
    return JSON.parse(weeksJson);
  } catch {
    return [];
  }
}

/**
 * 检查课程是否在指定周次
 */
function isWeekInSchedule(weeksJson: string, week: number): boolean {
  const weeks = parseWeeksJson(weeksJson);
  return weeks.includes(week);
}

/**
 * 格式化周次显示
 */
function formatWeeks(weeksJson: string): string {
  const weeks = parseWeeksJson(weeksJson);
  if (weeks.length === 0) return '';

  // 连续周次合并显示，如 [1,2,3,4,5] => "1-5周"
  const ranges: string[] = [];
  let start = weeks[0];
  let end = weeks[0];

  for (let i = 1; i < weeks.length; i++) {
    if (weeks[i] === end + 1) {
      end = weeks[i];
    } else {
      ranges.push(start === end ? `${start}` : `${start}-${end}`);
      start = weeks[i];
      end = weeks[i];
    }
  }
  ranges.push(start === end ? `${start}` : `${start}-${end}`);

  return ranges.join(',') + '周';
}
```

## 注意事项

1. **多课程处理**：同一单元格可能有多门课程（不同周次），需要循环展示或提示
2. **节次范围**：课程可能跨越多节（如1-2节），需要合并单元格或标识
3. **周次过滤**：提供周次筛选功能，方便查看特定周的安排
4. **响应式设计**：课表在小屏幕上需要考虑横向滚动或列表视图
5. **打印功能**：可选支持课表打印导出
