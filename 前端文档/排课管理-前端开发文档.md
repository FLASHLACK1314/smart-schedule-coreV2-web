# 排课管理 - 前端开发文档

## 功能说明

### 功能描述

管理系统中的排课记录，支持手动添加、修改、删除排课信息。

### 主要业务

- 分页查询排课记录（支持按学期、教学班、教室、教师、星期、状态筛选）
- 添加排课记录（指定教学班、教室、时间、周次等）
- 更新排课记录（锁定记录不可更新）
- 删除排课记录（锁定记录不可删除）

### 业务背景

- 排课是教学班在指定时间、指定教室的上课安排
- 一条排课记录包含：教学班、教室、星期、节次范围、上课周次
- 状态分为预览（0）和正式（1）两种

### 1. 分页查询接口

**路径**：`GET /v1/schedule/getPage`

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| page | number | 是 | 1 | 页码 |
| size | number | 是 | 10 | 每页记录数 |
| semester_uuid | string | 否 | - | 学期UUID |
| teaching_class_uuid | string | 否 | - | 教学班UUID |
| classroom_uuid | string | 否 | - | 教室UUID |
| teacher_uuid | string | 否 | - | 教师UUID |
| day_of_week | number | 否 | - | 星期几(1-7) |

## 页面功能

### 核心功能

- 分页展示排课记录列表
- 多条件筛选（学期、教学班、教室、教师、星期、状态）
- 添加排课（对话框）
- 编辑排课（对话框，锁定记录不可编辑）
- 删除排课（二次确认，锁定记录不可删除）

### 表格列设计

| 列名 | 字段 | 说明 |
|------|------|------|
| 学期 | semester_name | - |
| 教学班 | teaching_class_name | - |
| 课程 | course_name | - |
| 教师 | teacher_name | - |
| 教室 | classroom_name | - |
| 星期 | day_of_week | 1-7对应周一到周日 |
| 节次 | section_start ~ section_end | 如"1-2节" |
| 周次 | weeks_json | JSON数组 |
| 状态 | status | 0预览/1正式 |
| 锁定 | is_locked | 布尔值 |
| 操作 | - | 编辑/删除按钮 |

### 交互说明

1. **筛选功能**：点击筛选按钮展开筛选表单，支持多条件组合筛选
2. **添加排课**：点击"添加排课"按钮，弹出表单对话框
3. **编辑排课**：点击表格行的"编辑"按钮，弹出预填充表单对话框
   - 如果记录已锁定（is_locked=true），则禁用编辑按钮
4. **删除排课**：点击表格行的"删除"按钮，弹出二次确认对话框
   - 如果记录已锁定（is_locked=true），则禁用删除按钮

## 命名规范

> **重要**：所有字段统一使用蛇形命名（snake_case）

- **URL 查询参数**：蛇形命名，如 `semester_uuid`、`day_of_week`
- **请求体字段**：蛇形命名，如 `semester_uuid`、`teaching_class_uuid`
- **响应体字段**：蛇形命名，如 `schedule_uuid`、`teaching_class_name`

## 注意事项

1. **锁定记录**：已锁定的排课记录（is_locked=true）不允许修改和删除
2. **节次范围**：section_start 必须 <= section_end
3. **星期范围**：day_of_week 取值范围 1-7
4. **周次格式**：weeks_json 必须是合法的 JSON 数组字符串
5. **状态说明**：
   - 0 = 预览方案（临时排课，可修改）
   - 1 = 正式执行（正式排课，不可随意修改）
