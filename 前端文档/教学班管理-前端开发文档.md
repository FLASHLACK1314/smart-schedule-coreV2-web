# 教学班管理 - 前端开发文档

## 功能说明

**功能描述**：管理系统中的教学班信息，教学班是排课的业务主体，关联课程、教师和学期

**主要业务**：
- 创建教学班（指定课程、教师、学期）
- 查询教学班信息（支持按课程、教师、学期筛选）
- 更新教学班基本信息
- 删除教学班记录

**业务背景**：
- **教学班**（Teaching Class）是临时的上课组织单位，区别于行政班级
- 示例："高等数学-张老师-计科2101+2102" 表示张老师教授的高等数学课，包含计科2101和2102两个行政班的学生
- 教学班是排课的核心单位，后续的排课记录将关联到教学班

**示例场景**：新学期开学前，教务管理员需要为每门课程创建教学班，指定任课教师和所属学期，为后续排课做准备

### 1. 分页查询接口

**路径**：`GET /v1/teachingClass/getPage`

**说明**：获取教学班分页列表，支持多条件筛选

**查询参数**（蛇形命名 snake_case）：

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| page | number | 是 | 1 | 页码 |
| size | number | 是 | 10 | 每页记录数 |
| course_uuid | string | 否 | - | 课程UUID（筛选指定课程的教学班） |
| teacher_uuid | string | 否 | - | 教师UUID（筛选指定教师的教学班） |
| semester_uuid | string | 否 | - | 学期UUID（筛选指定学期的教学班） |

**响应示例**：

```typescript
{
  code: 200,
  message: "获取教学班分页信息成功",
  data: {
    total: 45,
    page: 1,
    size: 10,
    records: [
      {
        teachingClassUuid: "uuid-1",
        courseName: "高等数学",
        teacherName: "张教授",
        semesterName: "2024-2025学年第一学期",
        teachingClassName: "高等数学-张教授-计科2101+2102"
      },
      {
        teachingClassUuid: "uuid-2",
        courseName: "数据结构",
        teacherName: "李教授",
        semesterName: "2024-2025学年第一学期",
        teachingClassName: "数据结构-李教授-计科2101"
      }
    ]
  }
}
```

**响应字段说明**：

| 字段路径 | 类型 | 说明 |
|----------|------|------|
| total | number | 总记录数 |
| page | number | 当前页码 |
| size | number | 每页记录数 |
| records | array | 教学班记录数组 |
| records[].teachingClassUuid | string | 教学班UUID |
| records[].courseName | string | 课程名称 |
| records[].teacherName | string | 教师名称 |
| records[].semesterName | string | 学期名称 |
| records[].teachingClassName | string | 教学班名称 |

### 交互细节

#### 筛选区域

**课程下拉框**：
- 数据源：调用课程分页接口获取课程列表
- 选择课程后筛选该课程的所有教学班

**教师下拉框**：
- 数据源：调用教师分页接口获取教师列表
- 选择教师后筛选该教师的所有教学班

**学期下拉框**：
- 数据源：调用学期分页接口获取学期列表
- 选择学期后筛选该学期的所有教学班

**查询按钮**：
- 点击后根据筛选条件查询第1页

**重置按钮**：
- 清空所有筛选条件
- 重新加载第1页数据

---

#### 表格操作

**编辑按钮**：
- 点击后打开编辑对话框
- 回显当前教学班信息

**删除按钮**：
- 点击后弹出二次确认对话框
- 确认后调用删除接口
- 删除成功后刷新当前页

## 注意事项

1. **教学班命名规范**：
   - 建议格式：`课程名-教师名-班级组合`
   - 示例：`高等数学-张教授-计科2101+2102`
   - 可在前端添加命名提示或自动生成建议

2. **权限控制**：
   - 仅 SYSTEM_ADMIN 和 ACADEMIC_ADMIN 可以添加/编辑/删除
   - 其他角色（TEACHER、STUDENT）仅可查看
   - 操作按钮需根据用户角色显示/隐藏

3. **下拉数据加载**：
   - 课程、教师、学期下拉框数据需要在对话框打开时加载
   - 考虑使用懒加载或搜索功能优化性能

4. **删除约束**：
   - 教学班可能已关联排课记录（sc_schedule）
   - 删除前建议检查是否存在关联数据
   - 如有约束，后端会返回错误提示

5. **数据回显**：
   - 编辑时需要根据教学班当前的课程、教师、学期UUID回显下拉框
   - 可能需要先调用 `getTeachingClass` 接口获取完整信息

6. **业务理解**：
   - 教学班是排课的核心单位
   - 一个教学班对应一门课程、一个教师、一个学期
   - 一个教学班可以包含多个行政班的学生（通过 sc_teaching_class_class 关联表）
