# 学生管理 - 前端开发文档

## 功能说明

**功能描述**：管理系统中的学生信息，包括学生的学号、姓名、所属行政班级等基本信息

**主要业务**：
- 添加新学生到指定行政班级
- 查询学生信息（支持按学号、姓名、班级、专业、学院筛选）
- 更新学生基本信息（包括班级调整）
- 删除学生记录

**示例场景**：新学期开学时，教务管理员需要为新生创建学号并分配到对应班级；学生转专业时需要调整班级信息

### 主要接口表格

### 1. 分页查询接口

**路径**：`GET /v1/student/getPage`

**说明**：获取学生分页列表，支持多条件筛选

**查询参数**（蛇形命名 snake_case）：

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| page | number | 是 | 1 | 页码 |
| size | number | 是 | 10 | 每页记录数 |
| student_name | string | 否 | - | 学生姓名（模糊匹配） |
| student_id | string | 否 | - | 学号（精确匹配） |
| class_uuid | string | 否 | - | 行政班级UUID |
| major_uuid | string | 否 | - | 专业UUID |
| department_uuid | string | 否 | - | 学院UUID |

**响应示例**：

```typescript
{
  code: 200,
  message: "获取学生分页信息成功",
  data: {
    total: 150,
    page: 1,
    size: 10,
    records: [
      {
        studentUuid: "uuid-1",
        studentId: "202301001",
        studentName: "张三",
        classInfo: {
          classUuid: "class-uuid-1",
          className: "计科2101班",
          majorInfo: {
            majorUuid: "major-uuid-1",
            departmentUuid: "dept-uuid-1",
            departmentName: "计算机学院",
            majorNum: "CS001",
            majorName: "计算机科学与技术"
          }
        }
      }
    ]
  }
}
```

**响应字段说明**：

| 字段路径 | 类型 | 说明 |
|----------|------|------|
| total | number | 总记录数 |
| page | number | 当前页码 |
| size | number | 每页记录数 |
| records | array | 学生记录数组 |
| records[].studentUuid | string | 学生UUID |
| records[].studentId | string | 学号 |
| records[].studentName | string | 学生姓名 |
| records[].classInfo.classUuid | string | 行政班级UUID |
| records[].classInfo.className | string | 行政班级名称 |
| records[].classInfo.majorInfo.majorUuid | string | 专业UUID |
| records[].classInfo.majorInfo.departmentUuid | string | 学院UUID |
| records[].classInfo.majorInfo.departmentName | string | 学院名称 |
| records[].classInfo.majorInfo.majorName | string | 专业名称 |

## 页面功能

### 核心功能（checkbox 列表）

- [ ] 分页展示学生列表
- [ ] 多条件筛选（学号、姓名、学院、专业、班级）
- [ ] 添加新学生
- [ ] 编辑学生信息
- [ ] 删除学生（单个删除）

---

### 交互细节

#### 筛选区域

**学院下拉框**：
- 数据源：调用学院接口获取
- 选择学院后，自动清空并刷新专业下拉框
- 选择学院后，自动清空并刷新班级下拉框

**专业下拉框**：
- 数据源：根据选择的学院调用专业接口筛选
- 仅在选择了学院后才启用
- 选择专业后，自动清空并刷新班级下拉框

**班级下拉框**：
- 数据源：根据选择的学院和专业调用班级接口筛选
- 支持级联筛选（按学院→专业→班级）

**学号输入框**：
- 精确匹配查询
- 支持部分输入

**姓名输入框**：
- 模糊匹配查询
- 支持部分输入

**查询按钮**：
- 点击后根据筛选条件查询第1页

**重置按钮**：
- 清空所有筛选条件
- 重新加载第1页数据

---

#### 表格操作

**编辑按钮**：
- 点击后打开编辑对话框
- 回显当前学生信息（不包含密码）
- 学号不可修改（作为唯一标识）

**删除按钮**：
- 点击后弹出二次确认对话框
- 确认后调用删除接口
- 删除成功后刷新当前页

### 添加对话框字段

**对话框标题**：添加学生

**表单字段**：

| 字段名 | 类型 | 必填 | 交互说明 |
|--------|------|------|----------|
| 学号 | string | 是 | 输入框，失焦时检查唯一性 |
| 姓名 | string | 是 | 输入框 |
| 学院 | string | 是 | 下拉框，选择后级联专业/班级 |
| 专业 | string | 是 | 下拉框，依赖学院选择 |
| 班级 | string | 是 | 下拉框，依赖学院和专业选择 |
| 密码 | string | 是 | 密码输入框，需二次确认 |

**表单验证规则**：
- 学号：必填，长度限制（根据实际学号规则），失焦时调用接口检查唯一性
- 姓名：必填，中文姓名格式
- 学院/专业/班级：必填，级联选择
- 密码：必填，最小长度8位，需包含字母和数字

**提交逻辑**：
- 表单验证通过后，调用添加接口
- 成功后关闭对话框并刷新列表到第1页
- 失败则显示错误提示，对话框保持打开

---

### 编辑对话框字段

**对话框标题**：编辑学生信息

**表单字段**：

| 字段名 | 类型 | 必填 | 交互说明 |
|--------|------|------|----------|
| 学号 | string | 是 | 输入框，禁用状态（不可修改） |
| 姓名 | string | 是 | 输入框 |
| 学院 | string | 是 | 下拉框，选择后级联专业/班级 |
| 专业 | string | 是 | 下拉框，依赖学院选择 |
| 班级 | string | 是 | 下拉框，依赖学院和专业选择 |
| 新密码 | string | 否 | 密码输入框，如填写则需二次确认；留空则不更新密码 |

**表单验证规则**：
- 姓名：必填，中文姓名格式
- 学院/专业/班级：必填，级联选择
- 新密码：选填，如填写则最小长度8位，需包含字母和数字

**回显逻辑**：
- 学号：禁用状态，显示当前学号
- 其他字段：根据学生当前信息回显

**提交逻辑**：
- 表单验证通过后，调用更新接口
- 如果新密码为空，请求体中不包含 `studentPassword` 字段
- 成功后关闭对话框并刷新当前页
- 失败则显示错误提示，对话框保持打开

## 注意事项

1. **学号唯一性**：添加学生时，学号在系统内必须唯一，建议在失焦时调用接口检查或依赖后端返回的错误提示

2. **密码处理**：
   - 添加学生时密码必填
   - 编辑学生时密码选填，留空则不更新
   - 前端明文传递，后端使用 `PasswordUtil.encrypt()` 加密存储

3. **级联筛选**：
   - 学院→专业→班级三级级联
   - 清空上级选择时，需级联清空下级选项

4. **权限控制**：
   - 仅 SYSTEM_ADMIN 和 ACADEMIC_ADMIN 可以添加/编辑/删除
   - 其他角色（TEACHER、STUDENT）仅可查看

5. **数据回显**：编辑时需完整回显学生的学院、专业、班级信息

6. **学号不可修改**：学号作为学生的唯一标识，编辑时禁用修改
