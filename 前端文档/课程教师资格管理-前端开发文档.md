# 课程教师资格管理 - 前端开发文档

## 功能说明

**功能描述**：管理课程与教师的授课资格关联关系

**示例**：例如，为"高等数学"课程添加张老师、李老师等具有授课资格的教师，确保只有具备资格的教师才能被安排讲授该课程

---

## 页面信息

**页面路径**：`/course-qualification-management`

**路由名称**：`CourseQualificationManagement`

**可见用户**：`SYSTEM_ADMIN`、`ACADEMIC_ADMIN`、`TEACHER`、`STUDENT`

> 注：添加/删除操作仅 SYSTEM_ADMIN 和 ACADEMIC_ADMIN 可见，所有角色均可查看

---

## API 接口

> 接口详细信息请使用 MCP 工具从 OpenAPI Spec 获取

### 主要接口

| 功能 | 方法 | 路径 | 权限 | 说明 |
|------|------|--------|------|------|
| 分页查询 | GET | `/v1/courseQualification/getPage` | ALL | 获取列表，支持课程/教师筛选 |
| 添加资格 | POST | `/v1/courseQualification/add` | ADMIN | 为课程添加授课教师 |
| 删除资格 | DELETE | `/v1/courseQualification/delete` | ADMIN | 删除授课教师资格 |

### 分页查询接口

**路径**：`GET /v1/courseQualification/getPage`

**查询参数**（蛇形命名 snake_case）：
- `page` (number, 必填) - 页码
- `size` (number, 必填) - 每页数量
- `course_uuid` (string, 可选) - 按课程UUID筛选
- `teacher_uuid` (string, 可选) - 按教师UUID筛选

**响应字段**：
```typescript
{
  code: 200,
  message: "获取资格关联分页信息成功",
  data: {
    total: number,           // 总记录数
    page: number,            // 当前页码
    size: number,            // 每页记录数
    records: Array<{
      courseQualificationUuid: string,  // 关联关系UUID
      courseUuid: string,               // 课程UUID
      courseName: string,               // 课程名称
      teacherUuid: string,              // 教师UUID
      teacherName: string,              // 教师姓名
      teacherTitle: string,             // 教师职称
      departmentUuid: string,           // 学院UUID
      departmentName: string            // 学院名称
    }>
  }
}
```

### 添加接口

**路径**：`POST /v1/courseQualification/add`

**请求体字段**（驼峰命名 camelCase）：
```typescript
{
  courseUuid: string,   // 课程UUID（必填）
  teacherUuid: string   // 教师UUID（必填）
}
```

**业务规则**：
- 防止重复添加同一课程-教师组合
- 课程UUID和教师UUID必须有效

### 删除接口

**路径**：`DELETE /v1/courseQualification/delete`

**查询参数**（蛇形命名 snake_case）：
- `qualification_uuid` (string, 必填) - 关联记录UUID

## 页面功能

### 核心功能
- [x] 列表展示（表格形式）- 显示课程名称、教师姓名、教师职称、学院名称
- [x] 搜索/筛选功能 - 支持按课程、教师筛选
- [x] 添加功能（对话框）- 选择课程和教师创建关联
- [ ] 编辑功能 - 无需编辑，删除后重新添加即可
- [x] 删除功能（二次确认）

### 交互细节
- 使用 `useMessage` composable 进行消息提示
- 禁止使用浏览器原生 `alert()`
- 加载状态显示（按钮禁用、表格加载遮罩）
- 空数据提示（暂无数据）
- 删除前二次确认（确认对话框）
- 添加成功后刷新列表
- 添加/删除时校验用户权限

### 表格列设计
| 列名 | 字段 | 说明 |
|------|------|------|
| 课程名称 | `courseName` | 关联的课程 |
| 教师姓名 | `teacherName` | 具备资格的教师 |
| 教师职称 | `teacherTitle` | 教师职称（讲师/副教授等） |
| 所属学院 | `departmentName` | 教师所属学院 |
| 操作 | - | 删除按钮 |

### 添加对话框字段
| 字段 | 类型 | 说明 |
|------|------|------|
| 课程 | 下拉选择 | 从课程列表选择（需调用课程API） |
| 教师 | 下拉选择 | 从教师列表选择（需调用教师API） |

## 额外说明

### 权限控制
- 添加/删除按钮仅对 `SYSTEM_ADMIN` 和 `ACADEMIC_ADMIN` 显示
- 使用 `@RequireRole` 注解控制后端权限
- 前端可通过用户角色控制按钮显示/隐藏

### 下拉选择数据源
- 课程下拉：调用 `/v1/course/getPage` 获取课程列表
- 教师下拉：调用 `/v1/teacher/getPage` 获取教师列表
- 考虑添加搜索功能提升用户体验（如果课程/教师数量较多）

### 防止重复
- 后端已实现防重复逻辑
- 前端可在添加成功后刷新列表
- 考虑在提交前校验是否已存在相同组合（可选优化）
